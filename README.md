# wm-sz-status

Даты, таймер и статусы совместных закупок we make! вместе для makers-shop.team.

- `wm-status.js` — подключается в Тильде; оживляет опубликованные блоки таймера и статуса.
- `sz-status.json` — номер текущей СЗ, даты и этапы. Обновляется автоматически
  из рабочего проекта (скрипты/поставки-cs.py), руками не править.
